# NOT Gate Simulation

## Objective

To understand and verify the operation of a NOT gate using Logisim Evolution.

## Software Used

* Logisim Evolution v5.0.0

## Boolean Expression

**Y = A̅**

## Truth Table

| A | Y |
| - | - |
| 0 | 1 |
| 1 | 0 |

## Simulation

The NOT gate was designed and tested using Logisim Evolution.

## Observation

The output of a NOT gate is the complement of the input. When the input is LOW, the output becomes HIGH, and when the input is HIGH, the output becomes LOW.

In the shown simulation:

A = 1
Y = 0

Therefore, the output device is not activated.

## Conclusion

The simulation successfully verified the truth table and operation of the NOT gate. The output was observed to be the logical complement of the input.
