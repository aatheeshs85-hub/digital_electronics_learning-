# D Latch Simulation

## Objective

To design and verify the operation of a D Latch using Logisim Evolution.

## Software Used

- Logisim Evolution v5.0.0

## Description

A D Latch is a level-sensitive sequential logic circuit that stores one bit of data. It has two inputs, Data (D) and Enable (E), and two outputs, Q and Q̅. When the enable input is HIGH, the output follows the data input. When the enable input is LOW, the circuit retains its previous state.

## Inputs and Outputs

**Inputs:** D, E

**Outputs:** Q, Q̅

## Boolean Expressions

- **D̅ = NOT D**
- **A = (D · E)'**
- **B = (D̅ · E)'**
- **Q = (A · Q̅)'**
- **Q̅ = (B · Q)'**

A and B are internal signals generated by the NAND gates.

## Simulation

The circuit uses NAND gates and a NOT gate to implement the D Latch.

For the input conditions:

- D = 0
- E = 0

The latch retains its previous state because the enable input is LOW.

## Truth Table

| E | D | Q | Q̅ | Operation |
|---|---|---|---|---|
| 0 | 0 | Previous state | Previous state | Hold |
| 0 | 1 | Previous state | Previous state | Hold |
| 1 | 0 | 0 | 1 | Reset |
| 1 | 1 | 1 | 0 | Set |

## Uses

- Temporary storage of one bit of data.
- Data buffering in digital circuits.
- Registers and memory-related circuits.

## Observation

The output Q follows the data input D when the enable input E is HIGH. When E is LOW, the output retains its previous state. The output Q̅ is the complement of Q during normal operation.

## Conclusion

The D Latch was designed and simulated using NAND gates and a NOT gate in Logisim Evolution v5.0.0.
