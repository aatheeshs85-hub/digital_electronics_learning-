# BCD to Binary Converter Simulation

## Objective

To design and verify the operation of a BCD to Binary Converter using Logisim Evolution.

## Software Used

- Logisim Evolution v5.0.0

## Description

A BCD to Binary Converter is a combinational logic circuit that converts a decimal digit represented in Binary-Coded Decimal (BCD) format into its equivalent binary representation.

The circuit uses logic gates such as AND, OR, NOT, and XOR to perform the conversion.

## Inputs and Outputs

**Input Lines:**
- B4
- B3
- B2
- B1
- B0

**Output Lines:**
- A
- B
- C
- D
- E

## Boolean Expressions

- A=B0
- B=B1(EX OR)B4
- C=B4'B2 + B4B2B1' + B4B2'B1
- D=B4'B3 + B4B3' + B4B3'B2'
- E=B3B4 + B1B2B4

## Simulation

The circuit was designed using Logisim Evolution v5.0.0. The input pins were varied to observe the corresponding output combinations.

The output pins A, B, C, D, and E represent the five output bits generated by the implemented logic.
