# 4-Bit Parallel Adder Simulation

## Objective

To design and verify the operation of a **4-Bit Parallel Adder** using Logisim Evolution.

## Software Used

- Logisim Evolution v5.0.0

## Description

A **4-Bit Parallel Adder** is a combinational logic circuit used to add two 4-bit binary numbers. It consists of four Full Adder stages connected in cascade.

The circuit has:

- **A0, A1, A2, A3** – First 4-bit input
- **B0, B1, B2, B3** – Second 4-bit input
- **Ci** – Initial Carry Input
- **S0, S1, S2, S3** – 4-bit Sum Output
- **C3** – Final Carry Output

The carry generated by each Full Adder is passed to the next stage.

## Boolean Expressions

For each Full Adder stage:

**S = A ⊕ B ⊕ C**

**Cout = AB + C(A ⊕ B)**

For the complete 4-bit adder:

**S3 S2 S1 S0 = A3 A2 A1 A0 + B3 B2 B1 B0 + Ci**


## Simulation

The 4-Bit Parallel Adder was designed and tested using **Logisim Evolution v5.0.0**.

For the shown simulation:

**A = 0011**

**B = 0101**

**Ci = 0**

Therefore:

**Sum = 1000**

**C3 = 0**

Hence:

**0011 + 0101 = 1000**

## Observation

The circuit successfully adds two 4-bit binary numbers. The carry output from each Full Adder is connected to the carry input of the next stage, allowing the addition to proceed from the least significant bit to the most significant bit.

## Conclusion

The 4-Bit Parallel Adder was successfully designed and simulated using Logisim Evolution.
